# Developing raradio

This file guides agents working on the raradio repository.
Follow [CONTRIBUTING.md](CONTRIBUTING.md).
Keep the CLI usable without a UI, preserve source text and existing user work,
and verify behavior changes with the relevant model-free tests.

When changing production commands, keep the bundled
[raradio-audiobook Skill](raradio/skills/raradio-audiobook/SKILL.md) aligned with them.
Keep English and Chinese README instructions in sync.
