# raradio：本地有声书生产计划

[English](plan.md) | 简体中文

目标：面向喜欢终端和自动化的人，做一个容易安装、便于修订的有声书制作工具。配置人物和声音后批量生成有声书，将不明确的角色归属和生成异常集中交给人工复核。当前语音后端面向 Apple Silicon Mac；原文、分析结果、声音配置和音频独立保存，迁移要求见 [使用取舍与迁移](usage-notes.zh-CN.md)。

## 当前实现范围

以下功能已在代码中实现。自动化测试与短样本运行记录见 [验证记录](verification.zh-CN.md)；这些记录不能替代整章、整本的质量评测。

1. UTF-8 TXT 导入、UTF-16/UTF-32 BOM 识别，以及 `--encoding cp932` 等显式编码。确定性的候选章节与朗读片段保留原文偏移，结构问题进入复核；`--chapters none` 可关闭标题识别。
2. Ollama 结构化语义与人物分析；可纠正初步的旁白/对白分类，包括无引号发言与引号书名，不改写或重新划分原文。不确定或混有多个说话人的片段保持待确认。规则模式是离线启发式判断；single-voice 模式无需 LLM，全部文字用一个朗读者。这两种模式均不清除结构问题。
3. 可复用的角色和声音配置；角色确认、声音克隆参考文件与预设声音分别管理。新项目未指定声音语言时默认采用 `auto`，缺少新元数据的旧项目保留原有 Chinese 默认值。
4. SQLite 逐段进度；断点续跑、有限重试、单段重做、内容寻址音频缓存。显式 `--reanalyze` 重做自动标注，保留人工归属；`structure` 命令复核全文范围并应用章节、边界修改，不编辑原文，未变片段保留已有工作。
5. 空音频、时长、静音、削波检查；错误和可疑音频进入统一异常队列。
6. 章节 WAV、SRT、清单导出。拒绝把缺失或待确认的片段当完整章节发布。
7. 无模型诊断演示、自动化测试、短样本真实后端验证记录与迁移操作说明。

输入与修正流程见 [文本导入与结构复核](text-input.zh-CN.md)。这些接口支持日文原文处理和语言配置，日语发音、人物归属与整本质量仍须以真实样本评估。声音语言配置不会翻译小说；日文转中文有声书需要独立、可复核且与原文范围对应的中文稿，这一翻译阶段尚未实现。

## 模块与接口

```text
TXT → script.split_text → Segment + 原文偏移
                            ↓
                  analysis.analyze (single-voice / rules / Ollama)
                            ↓
                 BookProject (SQLite + cast.json)
                     ↓             ↑
            backends.synthesize   异常复核
                     ↓             ↑
                  audio.inspect_wav
                     ↓
                  audio.export_chapters
```

`BookProject` 集中维护状态转换、角色确认、缓存失效和恢复。文本分析与 TTS 通过独立模块适配，分别提供无模型实现和本地模型实现。核心运行时仅依赖 Python 标准库，MLX 按需安装。详细数据契约见 [架构说明](architecture.zh-CN.md)。

状态：`PENDING_PARSE → NEEDS_REVIEW / READY → GENERATING → DONE / FAILED / NEEDS_REVIEW`。进程退出后，下一次生成恢复遗留的 `GENERATING`；同一项目只允许一个写入者。

缓存依据：原文片段、角色声音配置、模型标识、后端版本、情绪、语速、采样设置及参考音频内容。已生成文件记录 SHA-256，恢复时校验。声音配置和标注变化会触发相关片段失效；模型权重在同一标识下被替换不会自动改变缓存键，因此验证记录还需保存模型版本。

## 后续阶段

以下能力尚未实现，阶段顺序用于组织工作，不表示已确定的发布版本或时间。

- 第二阶段：ASR 回读文本差异、音色相似度检查、提供音频路径便于试听的 CLI 复核命令、角色批量确认。
- 第三阶段：EPUB 导入、带章节 M4B / MP3、响度标准化、受控备用声音、模型安装与能力探测。
- 第四阶段：跨章节人物记忆、真实小说标注评测、吞吐量优化。

当前波形检查不能证明读音或角色音色正确。新增 ASR、音色评分时，应说明模型、评测样本与误判边界。诊断音仅用于验证流水线，不能当成有声书试听。

文本和语音的候选后端、插件接口及评测要求见 [后端选择与扩展路线](backend-strategy.zh-CN.md)。
